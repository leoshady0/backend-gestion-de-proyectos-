# FORJA development rules

- Preserve application behavior and visual design unless the user requests changes.
- This repository contains source code only. Never include real project records, invoices, contracts, exports, browser profiles, credentials, or customer information.
- Browser data is not synchronized by Git. Do not clear or migrate it without explicit authorization.
- Run `npm run check` before committing.
- Use `npm run sync:status` and `npm run sync:pull` before starting work on a computer.
- Stop and report conflicts. Do not use force pushes, hard resets, destructive clean commands, automatic stashing, or history rewriting on this development repository.
- Ask the user before creating external repositories, uploading code, changing access permissions, or performing destructive operations.
- Do not deploy automatically. Existing Sites deployment identity is intentionally excluded.
- Use task branches for concurrent work. Keep production data and credentials outside the repository.
